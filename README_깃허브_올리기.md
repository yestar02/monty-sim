# 학생용 몬티홀 시뮬레이터를 깃허브(GitHub Pages)에 올리는 방법

올리는 파일은 이 폴더의 `index.html` 하나입니다(학생 기기에서 열릴 시뮬레이터).

1. github.com에 로그인 → 오른쪽 위 `+` → `New repository`
   - 이름 예: `monty-sim` · Public 선택 · `Create repository`
2. 만든 저장소 화면에서 `uploading an existing file` 링크 → `index.html`을 끌어다 놓기 → `Commit changes`
3. 저장소 `Settings` → 왼쪽 `Pages` → `Build and deployment`에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택 → `Save`
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://<깃허브아이디>.github.io/monty-sim/`
5. 그 주소를 알려 주면 6번 슬라이드에 링크와 QR을 넣어 다시 만들어 드립니다.

참고
- 이 파일은 개인정보·수업 자료(정답 값, 교사 노트)가 없는 시뮬레이터뿐입니다. 저장소를 Public으로 둬도 학생 활동 화면만 공개됩니다.
- 올린 뒤 휴대폰에서 주소를 열어 문 3개가 나오는지 확인하세요.
